# LINE 好友邀請裂變 — 上線設定教學

> 目標：會員分享專屬連結 → 朋友加入 LINE 官方帳號並送出邀請碼 → 系統自動發 10 積分給邀請人。

完成順序：**① 建資料表 → ② 建 LINE 官方帳號 → ③ 拿 3 個金鑰 → ④ 填 Vercel 環境變數 → ⑤ 設 Webhook → ⑥ 測試**。

---

## ① 建立資料表（Supabase）

1. 前往 https://supabase.com/dashboard 登入，點進你的專案。
2. 左側選單點 **SQL Editor** → 右上角 **New query**。
3. 打開專案裡的 `migrations/referral_schema.sql`，把整個檔案內容複製貼上。
4. 按右下角 **Run**（或 Ctrl/Cmd + Enter）。
5. 看到 `Success. No rows returned` 即完成。
6. 驗證：左側 **Table Editor**，應該能看到新表 `referrals`、`points_ledger`；點 `user_profiles` 也會多出 `referral_code`、`points` 兩欄。

---

## ② 建立 LINE 官方帳號 + 啟用 Messaging API

> 如果你已經有官方帳號，跳到第 3 步。

1. 前往 **LINE Official Account Manager**：https://manager.line.biz/ ，用 LINE 帳號登入。
2. 點 **建立帳號（Create）**，填名稱（例如「88自醫健康優選」）、類別、地區 → 建立。
3. 進入該帳號後，左下角 **設定（Settings）** → **Messaging API** → **啟用 Messaging API（Enable）**。
   - 會要你選一個 **Provider**（提供者），沒有就新建一個（名稱隨意，例如「88自醫」）。
   - 啟用後，系統會自動在 LINE Developers 建立對應的 Channel。

---

## ③ 拿 3 個金鑰

前往 **LINE Developers Console**：https://developers.line.biz/console/
點你的 **Provider** → 點剛剛建立的 **Messaging API channel**，然後分別到下列分頁複製：

| 要拿的值 | 位置 | 環境變數名稱 |
|---|---|---|
| **Bot basic ID**（@開頭，例如 `@123abcde`） | 「**Messaging API**」分頁 → Bot information | `NEXT_PUBLIC_LINE_OA_BASIC_ID` |
| **Channel secret** | 「**Basic settings**」分頁 | `LINE_CHANNEL_SECRET` |
| **Channel access token (long-lived)** | 「**Messaging API**」分頁 → 最下方，按 **Issue** 產生 | `LINE_CHANNEL_ACCESS_TOKEN` |

> ⚠️ Channel secret 與 access token 是機密，只貼進 Vercel 環境變數，不要貼進程式碼或聊天室。
> Bot basic ID 一定要含 `@`，例如 `@123abcde`。

---

## ④ 填 Vercel 環境變數

1. 前往 https://vercel.com/ → 點你的專案 → **Settings** → **Environment Variables**。
2. 逐一新增以下變數（Environment 勾選 **Production**，建議 Preview 也勾）：

| Name | Value（範例） | 說明 |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://healthec.vercel.app` | 你的正式網址（有自訂網域就填自訂網域，邀請連結會用這個） |
| `NEXT_PUBLIC_LINE_OA_BASIC_ID` | `@123abcde` | 第③步的 Bot basic ID（含 @） |
| `LINE_CHANNEL_SECRET` | （第③步的值） | 驗證 webhook 簽章 |
| `LINE_CHANNEL_ACCESS_TOKEN` | （第③步的值） | 後台回覆訊息 |
| `NEXT_PUBLIC_LINE_COMMUNITY_URL` | `https://line.me/ti/g2/xxxx`（選填） | 加好友後自動推給朋友的社群連結 |
| `REFERRAL_POINTS` | `10`（選填，預設 10） | 每邀請一人發的積分 |

3. 存檔後，到 **Deployments** 分頁 → 最新一筆右側 **⋯** → **Redeploy**，讓新變數生效。
   （之後每次 git push 也會自動重新部署。）

## ⑤ 設定 Webhook + 關閉自動回覆

### 5-1 設定 Webhook URL（LINE Developers Console）
1. 回到 https://developers.line.biz/console/ → 你的 channel → 「**Messaging API**」分頁。
2. 找到 **Webhook settings** → **Edit** → 填入：
   ```
   https://你的網域/api/line/webhook
   ```
   例如 `https://healthec.vercel.app/api/line/webhook`
3. 按 **Update** → 按 **Verify**，出現 **Success** 代表後台接得到（要先完成第④步並 Redeploy）。
4. 把 **Use webhook** 開關打開 ✅。

### 5-2 關閉自動回覆（LINE Official Account Manager）
1. 回到 https://manager.line.biz/ → 你的帳號 → **設定** → **回應設定（Response settings）**。
2. 設定如下，webhook 才不會被內建罐頭訊息蓋掉：
   - **回應模式（Response mode）**：選 **Bot**（或「聊天機器人」）
   - **自動回應訊息（Auto-reply messages）**：**關閉**
   - **Webhook**：**開啟**
   - 加入好友的歡迎訊息（Greeting message）：可開可關，我們的程式在加好友時會自己回一則引導訊息。

## ⑥ 測試（建議用兩支手機 / 兩個 LINE 帳號）

1. **取得邀請連結**：用「邀請人」身分在網站登入 → 右上角 **會員** → **邀請好友賺積分** → 複製專屬連結（形如 `https://你的網域/invite/AB12CD`）。
2. **模擬朋友**：用「另一個 LINE 帳號」的手機打開該連結 → 點綠色 **一鍵加入 LINE** 按鈕。
3. LINE 會開啟官方帳號、自動帶入「我要加入！邀請碼 AB12CD」訊息 → 點 **加入** → 把訊息 **送出**。
4. 朋友會立刻收到 bot 回覆「已通知邀請你的朋友獲得 10 積分 🎁」（若有設社群連結也會一併送出）。
5. **驗收**：
   - 邀請人回網站 **會員中心 → 邀請好友賺積分**，積分 +10、出現一筆邀請紀錄。
   - 後台（超級管理員）**🎁 邀請裂變** 頁可看到總邀請數、發出積分與排行榜。

---

## 運作原理（重點 & 限制）

- **驗證的是「加入官方帳號 + 送出邀請碼」**，不是偵測「加入 OpenChat 社群」——因為 LINE 對社群入群完全沒有提供通知 API。加好友後 bot 會自動把社群連結推給朋友，等於一次帶進兩邊。
- **防刷**：同一個 LINE 帳號只能成功領一次好友禮（資料庫唯一鍵 + 原子函式保證）。
- 邀請碼為 6 碼英數（去掉易混淆的 0/O/1/I），會員第一次開啟邀請頁時自動產生。

## 常見問題排查

| 狀況 | 可能原因 / 解法 |
|---|---|
| Webhook 按 Verify 失敗 | ① 還沒 Redeploy；② `LINE_CHANNEL_SECRET` 沒填或填錯；③ URL 結尾要是 `/api/line/webhook` |
| 朋友送出邀請碼沒反應 | ① Use webhook 沒開；② 自動回應沒關，蓋掉了 webhook；③ access token 填錯 |
| 朋友收到回覆但邀請人沒加分 | ① 邀請碼打錯/連結錯；② 該 LINE 帳號之前已領過（只能領一次） |
| 邀請連結網域不對 | `NEXT_PUBLIC_SITE_URL` 要填你的正式網域，改完要 Redeploy |
| 一鍵按鈕沒帶入邀請碼 | 落地頁下方有邀請碼可手動複製，加好友後貼上送出即可 |
