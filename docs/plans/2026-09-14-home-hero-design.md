# 首頁首屏設計

用戶已選擇先重做首屏。沿用已討論的暖白、深綠方向，保留現有 Noto Sans TC 字型。

相較於純文字橫幅或大型情境照片，採用精簡文案搭配真實商品預覽：讓 Facebook 新客直接看到可買商品，手機避免大圖佔滿首屏。

範圍：抽出 HomeHero、替換原橫幅、品牌列加上可見品牌名稱。其他首頁區塊、訂單及賣貨便流程不更動。

主按鈕捲到既有人氣區；已搜尋或分類時回到當前商品結果。次入口連到健康自測。商品從既有首頁資料選最多三件有圖片且可購買的商品，顯示可購買規格最低價，沒有商品時只顯示文案。商品卡使用真實封面，不創造包裝或銷量。

驗證：編譯及現有文字檢查，桌面與手機 390px、320px 版面檢查；確認首屏商品可見、主按鈕目的地、商品與自測連結，未載入商品時不顯示空價格。先提供本機預覽。
