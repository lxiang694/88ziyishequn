# SOP：出貨與 7-11 交貨便

> **這份是給打包人員看的，不是給經營者看的。**
> 印出來貼在打包桌旁邊。
>
> 原則：**寧可慢一分鐘核對，不要快一分鐘出錯。**
> 出錯一筆的成本 = 來回運費 + 商品 + 重寄 + 客戶信任，
> 遠高於多花的那一分鐘。

---

## 一、每日時間表

| 時間 | 事情 |
|---|---|
| 09:30 | 到班，開後台看今日待出貨清單 |
| 09:30–10:00 | 揀貨（把今天所有訂單的商品先全部拿出來） |
| 10:00–11:30 | 逐筆核對 → 打包 → 貼單 |
| 11:30–12:00 | 送 7-11 交貨便 |
| 12:00 | 回報當日結果（格式見第六節） |

**截單時間：前一天 21:00。** 21:00 之後的訂單算隔天的。

---

## 二、揀貨

1. 後台 → 訂單管理 → 篩選「待出貨」
2. 列印出貨清單（或截圖到手機）
3. 依清單把商品全部集中到打包桌

**揀貨時就要看的兩件事：**

- **效期** —— 效期短的先出。剩不到 3 個月的**不要出**，回報給老闆
- **外觀** —— 瓶身有無滲漏、瓶蓋有無鬆動、標籤有無破損、玻璃有無裂痕

---

## 三、逐筆核對（最重要的一步）

**一次只處理一筆訂單。不要同時攤開三張單子。**

每一筆，出聲念一次（真的出聲，這會抓到眼睛抓不到的錯）：

```
訂單編號 ______
收件人 ______
電話 ______
門市 ______
商品：______ ×__ 、 ______ ×__
```

念完再對一次手上的東西。**品項對、數量對**，兩件都要單獨確認。

### 最常出錯的地方

| 錯誤 | 怎麼避免 |
|---|---|
| 規格搞混（500ml / 250ml） | 唸出來的時候一定要唸規格 |
| 同一客戶兩筆訂單混在一起 | 一次只處理一筆，打包完才拿下一張 |
| 數量看成 1 其實是 2 | 數量欄位用手指指著唸 |
| 贈品漏放 | 贈品跟商品一起揀，不要最後才想起來 |

## 四、打包規範

### 液體類（紫蘇油、茶籽油、沙棘籽油）—— 最高風險

**一瓶漏，整箱毀，而且客戶收到的是一箱油。**

1. 瓶蓋**先用手轉緊再確認一次**
2. 瓶口纏封口膜或膠帶一圈
3. 每瓶單獨用氣泡袋包起來（不是整批包在一起）
4. 兩瓶以上時，瓶與瓶之間要有緩衝物，不可以直接碰在一起
5. 箱內空隙全部填滿——**搖一搖，聽到東西在動就是沒填夠**
6. 箱外貼「易碎品」標示

### 玻璃罐裝

同上，緩衝要比塑膠瓶更厚。

### 鐵鍋

1. 重，箱子要用厚的，底部加強一層
2. 鍋子本身用氣泡布整個裹起來，鍋柄另外包
3. 不要跟油品裝同一箱（鐵鍋會壓破瓶子）

### 紅光燈

1. 原廠盒不要拆
2. 原廠盒外面再套一個箱子，中間填緩衝
3. 電源線、變壓器、說明書要在箱內，出貨前確認

### 一律要放的東西

- [ ] 出貨明細（訂單編號、品項、數量）
- [ ] 保存方式小卡（油品）
- [ ] 贈品（如果訂單上有）

---

## 五、7-11 交貨便

1. 後台列印交貨便標籤（或用店到店系統）
2. **貼標籤前最後看一次**：標籤上的門市 = 訂單上的門市
3. 標籤貼在箱子最大面，不要貼在接縫處、不要貼在膠帶上
4. 送到 7-11 櫃檯寄件
5. **收據一定要留**，拍照存檔
6. 回後台把該筆訂單改成「已出貨」

### 貨到付款特別注意

- 標籤上的**代收金額必須跟訂單金額完全一致**，一元都不能差
- 金額錯了客戶會當場拒收，整箱回頭
- 每一筆貨到付款，貼標籤前**單獨再確認一次金額**

## 六、當日回報格式

每天 12:00 前傳給老闆：

```
【出貨回報 ○/○】
應出貨：__ 筆
已出貨：__ 筆
未出貨：__ 筆

未出貨原因：
- 訂單 ______：缺貨（商品：______）
- 訂單 ______：門市有問題

異常：
- 訂單 ______：______ 效期只到 __ 月，先扣住沒出
- 庫存偏低：______ 剩 __ 件

交貨便收據：（照片）
```

**沒有異常也要回報，寫「無異常」。** 沒收到回報 = 老闆要自己來查。

---

## 七、遇到這些狀況，停下來問，不要自己決定

- 商品效期剩不到 3 個月
- 商品外觀有問題（滲漏、破損、標籤不清）
- 庫存不夠，只能出一部分
- 訂單上的門市名稱查不到
- 訂單金額看起來不對
- 客戶備註欄有特殊要求
- **任何你不確定的事**

問一句的成本是 30 秒。猜錯的成本是一筆訂單。

---

## 八、庫存回報（每週五）

每週五出完貨後，盤點一次並回報：

```
【週庫存回報 ○/○】
商品          剩餘數量
______        __
______        __

低於安全庫存的：
- ______（剩 __，安全庫存 __）
```

安全庫存數字見 `ops/data/商品清單.md`（待建立）。
