# SOP：面單上傳新比銳

適用對象：出貨的人（老闆或包貨夥伴）
執行時機：包裹打包完、要交店之前

---

## 這件事出錯的代價

面單上的**物流條碼**決定這個包裹屬於誰。檔名對不上內容，會同時造成兩個問題：

- 那筆訂單的包裹，貼著別人的面單 → 貨寄到別人手上
- 被冒名的那筆訂單，等於沒有面單 → 倉庫等一個不會到的包裹

這不是假設。2026/09/21 那批實際發生過：另存出來的
`CM2609214719432.pdf` 與 `CM2609214719459.pdf`，裡面裝的是同一張面單
（都是 719459）。原因是一筆一筆另存時，檔名靠手打，打錯沒有任何東西會攔。

**所以現在不再手打檔名。** 檔名一律由系統從面單內容讀出來。

---

## 流程

### 1. 賣貨便：一次把這批要出的都印出來

1. 進「賣家訂單」
2. **勾選**這批要出貨的訂單（可以複選）
3. 按「取交貨便代碼」
4. 按「列印交貨便代碼」→ 選「寄件單（A4雙排）」
5. 另存 PDF。**檔名隨便取**，不用管

> 一個賣場一份 PDF。三個賣場就重複三次，得到三份。
> 同一個賣場今天有 10 筆但只要出 3 筆，就只勾那 3 筆。

### 2. 後台：拆檔

1. 進後台 →「賣貨便轉單」→「面單處理」
2. （建議做）把這批的訂單號貼進第一個欄位
   - 從哪裡複製都可以，中間夾雜日期、金額、賣場名稱沒關係
   - 貼了才會幫你核對**漏印**和**多印**
3. 把剛才存的 PDF 全部選進來（三份一起選沒問題）
4. 按「開始拆檔」

畫面會告訴你：

| 提示 | 意思 | 怎麼處理 |
|---|---|---|
| 漏印 N 筆（紅色） | 清單上有，但 PDF 裡沒有 | 回賣貨便補印那幾筆，連同新 PDF 再丟一次 |
| 多印 N 筆（黃色） | PDF 裡有，但不在清單上 | 不用理，系統不會把它放進 ZIP |
| 某訂單在多份 PDF 都有 | 同一批印了兩次 | 不用理，取最後一份 |

> 漏印一定要處理完再往下。包裹出了、面單沒傳，貨到新比銳會對不上。

5. 按「下載 ZIP」，解壓縮到一個資料夾

檔案已經是 `CM…….pdf`，不用也不要去改檔名。

### 3. 新比銳：上傳

1. 開新比銳國際物流桌面程式
2. 「蝦皮相關」→「蝦皮面單上傳」→「選取」
3. 進到剛才解壓的資料夾，**全選**（支援多選）
4. 按「識別」，等幾秒
5. 看到 **7-11** 就是識別成功
6. 按「上傳」

---

## 注意

- 面單上有收件人姓名與取件門市。拆檔是在你自己的瀏覽器裡跑的，PDF
  不會上傳到我們的伺服器；但解壓出來的資料夾記得別留在共用電腦上。
- 這批做完就把資料夾刪掉，免得下一批誤選到上一批的舊面單 —— 舊面單
  傳上去，倉庫會等一個早就寄出的包裹。
- 系統在產出每一個檔案之前，會把自己做出來的 PDF 再讀一次，確認裡面
  只有一個訂單號而且正是檔名那個。對不上就整批停下來、不給檔案。
  如果真的跳出錯誤訊息，**不要想辦法繞過**，把訊息截圖回報。
