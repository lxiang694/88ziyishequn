# 法規紅線

> **所有對外文字的前置檢查。** 貼文、Line 訊息、商品頁、客服回覆、廣告素材——
> 送出之前一律過這份。AI 崗位的每一份提示詞都必須先讀這一份。
>
> 這不是建議事項。這裡列的每一條都有對應罰則，最低 4 萬，最高 2500 萬。

---

## 一、為什麼這份文件排在最前面

我們賣的是**食品、食品器具、一般商品**，不是藥品，也不是醫療器材。

這代表：我們可以講「這是什麼、怎麼做的、怎麼用、吃起來如何」，
**不能講「它對什麼病有用」**——即使那是真的，即使客戶自己先問的，
即使只是在 Line 私訊裡一對一講。

私訊也算廣告。衛生局的檢舉案件有相當比例來自截圖。

## 二、適用法條與罰則

| 法條 | 內容 | 罰則 |
|---|---|---|
| 食安法 §28 I | 食品標示、宣傳、廣告不得不實、誇張、易生誤解 | 4 萬 – 400 萬 |
| 食安法 §28 II | **食品不得為醫療效能之標示、宣傳或廣告** | 60 萬 – 500 萬 |
| 藥事法 §69 | 非藥物不得為醫療效能之標示、宣傳或廣告 | 60 萬 – 2500 萬 |
| 健康食品管理法 §6 | 未取得許可證不得標示保健功效 | 10 萬 – 100 萬 |
| 醫療器材管理法 §46 | 非醫療器材不得為醫療效能之標示、宣傳或廣告 | 60 萬 – 2500 萬 |
| 公平交易法 §21 | 不得為虛偽不實或引人錯誤之表示 | 5 萬 – 2500 萬 |
| 個資法 | 客戶姓名、電話、地址不得外流或作目的外利用 | 民刑事責任 |

## 三、絕對不能出現的詞

### A. 醫療效能（踩到就是 60 萬起跳）

```
治療、醫治、根治、痊癒、療效、有效改善○○症、預防○○病
抗癌、防癌、抑制腫瘤
降血壓、降血脂、降血糖、降膽固醇、穩定血糖
消炎、抗發炎、止痛、緩解疼痛
護肝、養肝、顧肝、解毒、排毒
增強免疫力、提高抵抗力、抗過敏
改善失眠、治療便秘、消除水腫
活血、通血管、清血管、預防中風、預防心肌梗塞
改善關節炎、修復軟骨、促進傷口癒合
殺菌、抗菌（指對人體時）
```

### B. 誇張不實（公平交易法 + 食安法 §28 I）

```
最、第一、唯一、頂級（無客觀依據時）
保證、絕對、百分百、無副作用、零風險
神效、特效、奇蹟、立即見效、包好
有效率 ○○%（沒有可公開查證的來源就不能寫）
「很多人吃了都說……」（沒有紀錄可佐證即屬引人錯誤）
```

### C. 灰色地帶（能不用就不用）

```
養生、調理、改善體質、淨化、修復、抗老
增強、提升○○力、食療
```

這些字本身不必然違法，但一旦與具體症狀或疾病放在同一句，
就會被整句認定為醫療效能宣稱。**判定看的是整體語意，不是單字。**

## 四、可以講的東西（這才是我們的文案素材庫）

| 類別 | 範例 |
|---|---|
| 成分與含量 | 「每 100g 含 Omega-3 ○○ mg」「以油酸為主要脂肪酸」 |
| 物理特性 | 「發煙點約 200°C」「質地清爽」「冷壓後呈金黃色」 |
| 產製過程 | 「低溫壓榨」「南投山區採收」「果實自然裂開才摘」「一年一收」 |
| 烹調用途 | 「拌麵線」「涼拌」「煎蛋中火不易起煙」「取代部分麻油」 |
| 感官描述 | 「不搶味」「順口」「有淡淡的堅果香」 |
| 保存與使用 | 「開封後三個月內用完風味最好」「避免放爐台旁」 |
| 來源故事 | 採收現場、產地、生產者、批次差異 |

**寫不出賣點的時候，答案永遠在「產製過程」跟「來源故事」，不在效果。**
野生茶籽油那頁就是照這個寫的，可以直接當範本。

## 五、營養素功能宣稱：唯一的例外，但要照抄

一般食品**唯一**可以講的「身體相關」敘述，是衛福部公告的**營養素生理功能敘述**，
而且必須符合兩個條件：

1. 該營養素含量達到公告的基準值
2. **逐字照抄官方句型**，不可以自己改寫、加強、延伸

合法句型範例：

```
維生素 A 有助於維持在暗處的視覺
維生素 D 可增進鈣吸收
維生素 C 有助於膠原蛋白的形成，具抗氧化作用
鈣是構成骨骼及牙齒的主要成分
鐵是組成血紅素與肌紅素的重要成分
膳食纖維有助於維持消化道機能
菸鹼素有助於維持皮膚、神經系統的健康
```

違法的改寫範例（同一件事，寫法不同就違法）：

```
✗ 補充維生素 D 可以幫助鈣吸收，預防骨質疏鬆   ← 加了疾病
✗ 維生素 C 抗氧化，能抗老化、增強免疫          ← 延伸超出句型
✗ 我們的鈣吸收率特別好                        ← 誇張且無依據
```

**規則：官方句型一個字都不要動，前後也不要接自己的補充說明。**

## 六、分商品的特別注意

### 🔴 紅光／近紅外線燈 —— 我們風險最高的商品

只要文案出現**任何**醫療用途（消炎、止痛、促進循環、改善關節、
加速修復、傷口癒合、改善睡眠），這盞燈在法律上就變成「醫療器材」。
沒有醫療器材許可證而作此宣稱 → 醫療器材管理法 §46，**60 萬起跳**。

- 可以寫：規格、波長、功率、照射距離、使用時間、材質、安全設計、保固
- 可以寫：使用情境（「睡前放在客廳用」「冬天覺得暖」）
- **不可以寫**：任何跟身體反應、症狀、恢復有關的敘述
- 客戶問「這個對我的膝蓋有沒有幫助」→ 標準回覆見 `ops/data/常見問答.md`

**如果賣家或原廠有給任何醫療器材許可證字號，立刻告訴我，整個規則會不一樣。**

### 🟡 鐵鍋

- 「用鐵鍋炒菜可以補鐵」是**保健功效宣稱**，食品器具不得為此宣稱，有風險
- 可以寫：材質、厚度、開鍋養鍋方法、導熱、重量、保養、不沾的物理原理
- 不可以寫：補鐵、改善貧血

### 🟡 營養素／保健食品

- 除非產品有**小綠人健康食品標章**，否則不可宣稱任何保健功效
- 有標章 → 只能宣稱許可證上登載的那一項，逐字照抄
- 沒有標章 → 只能用第五節的營養素功能宣稱句型

### 🟢 紫蘇油、茶籽油、沙棘籽油

- 一般食品，照第四節的素材庫寫
- 脂肪酸組成可以寫（是成分，不是效果）
- 「Omega-3 對心血管有益」← 不行，這是效果

### 🟡 食療產品

「食療」兩個字本身就在灰色地帶。商品命名若已經包含，維持現狀，
但文案不要再往症狀方向延伸。

## 七、客服私訊的三條線

1. **客戶自己說出病名，我們不接話。**
   「我有糖尿病能吃嗎」→ 不回答能不能改善，回答成分與建議諮詢醫師。

2. **不做個別健康建議。** 我們不知道對方的用藥、病史、過敏。
   標準句：「這部分建議先問一下您的醫師或營養師，我們只能提供成分資料。」

3. **不要把客戶個資貼進任何 AI 對話。**
   要 AI 幫忙寫回覆時，姓名改成「客戶」、電話地址整段拿掉。

## 八、發現已經寫出去的內容違規怎麼辦

1. 立刻下架／刪文（FB、IG、Threads、Line 社群、網站都要）
2. 記錄在 `ops/data/違規紀錄.md`：日期、平台、原文、為什麼違規
3. 不要只刪那一篇——同一句話通常散在很多地方，全站搜一次

## 九、這份文件的使用方式

- 每一個 AI 崗位的提示詞開頭，都要放這一份的連結或全文
- 每一篇對外文字送出前，自己過一次第三節的詞表
