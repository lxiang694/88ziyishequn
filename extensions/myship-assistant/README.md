# 健康優選・賣貨便助手 0.2.5

已確認0.2.2能在比特瀏覽器完成自動匯入。0.2.3修正匯入成功後無法讀取結果按鈕的問題；自動下載及回填仍需在實際瀏覽器驗證。

## 從 0.2.0 至 0.2.4 更新

1. 關閉正在使用助手的比特瀏覽器環境。將新版解壓後的全部檔案，覆蓋到原本安裝助手的資料夾；manifest.json 應顯示版本 0.2.5。
2. 重新開啟原本的比特瀏覽器環境，使其載入覆蓋後的本機擴展。保留原擴展項目及資料夾，以保留助手的批次狀態。
3. 在健康優選工作台按 Ctrl＋F5，再按「檢查助手連線」。成功時顯示「助手 0.2.5 已連接」。賣貨便匯入頁也需重新整理。

0.2.3 支援實際結果頁的「下載匯入結果」按鈕。助手直接讀取該頁對應的官方結果檔，核對完整資料後更新出貨；不會再次提交匯入。若原批次已全部人工核對成功，按「讀回上一批結果」也會結束舊任務並開放多筆處理。解除保留不視為驗收成功。

0.2.2 修正真正匯入頁 https://myship.7-11.com.tw/orderimport/import 未被納入辨識範圍的問題；安裝設定、分頁搜尋、上傳及結果讀取均加入 /orderimport/。保留頁面、唯一上傳欄位及結果檔的核對。找不到分頁、頁面未載入助手，以及上傳欄位檢查失敗，會分別顯示具體原因。

0.2.1 改用相容的瀏覽器訊息回覆方式，核對目前分頁網址以支援從其他後台頁面切入，並區分未載入助手、背景無回覆及連線中斷。若仍有錯誤，將完整訊息提供給開發者；本機模擬測試通過仍需以實際比特瀏覽器確認。

本機擴展更新方式依比特瀏覽器官方說明：覆蓋資料夾內容後重新啟動瀏覽器。說明連結：https://www.bitbrowser.net/hk/team-work/rich-extensions 。

## 第一次安裝

1. 解壓縮本資料夾，確認可以看到 manifest.json。
2. 比特瀏覽器主程式 → 擴展中心 → 添加自訂擴展 → 添加本地擴展，選取 manifest.json 所在資料夾。
3. 啟用「健康優選・賣貨便助手」。依比特瀏覽器提示，重新開啟用來管理第一個賣貨便賣場的瀏覽器環境。
4. 在這個環境登入健康優選及賣貨便。助手只處理健康優選中已配對至 GM2601252733206 的訂單。
5. 打開 https://www.88ziyishequn.com/admin/myship ，重新整理後應顯示「助手 0.2.5 已連接」。使用 healthec.vercel.app 的既有登入也可，但同一批請持續使用原本網址。

安裝權限僅涵蓋健康優選兩個正式網址、myship.7-11.com.tw 及助手的本機作業狀態。助手不要求密碼、Cookie 匯出、本機 API 金鑰或其他瀏覽器環境的控制權。

## 0.2.5 狀態同步

工作台載入後，助手會在目前健康優選分頁查詢指定賣場是否已有核對成功紀錄，自動恢復多筆處理資格。舊任務若已在後台全部結束，會同步完成，不要求原賣貨便分頁還存在。尚待核對的批次仍需讀回或顯式保留。正在處理的任務不會被狀態輪詢覆寫。

若原賣貨便分頁關閉，讀回時只重新尋找唯一的官方結果頁；不會把上傳指令送到新分頁。結果仍需通過原批次逐欄核對。缺少或有多個結果頁會提示操作方式。

## 每次操作

1. 在同一個瀏覽器環境打開賣貨便「訂單工具 → 訂單匯入」：https://myship.7-11.com.tw/orderimport/import 。請使用尚未選檔、未顯示上次結果的頁面，並只保留一個可用匯入頁。
2. 在健康優選選取本次待處理訂單，按「自動轉到賣貨便」。首次只能選1筆。
3. 保持兩個分頁開啟，助手會產生官方檔案、填入上傳欄位、點選匯入，並讀取結果檔。
4. 系統用原單號比對全部收件欄位、商品及金額，再保存有效的 CM 編號及更新已出貨。

檔案內容由助手在兩個指定網站之間傳遞，正常流程不需手動在下載資料夾找檔案。每批最多500筆，2 MB上限。既有已保留或已出貨訂單不能作為新的助手批次。

## 中斷時

若某批需要另行核對，可按「保留此批，繼續其他訂單」。這只解除助手目前任務的阻塞，伺服器原批次和訂單保留仍在；同一訂單不能再次上傳。新批次開始後，舊批次從「批次紀錄」讀取結果檔或核對成功編號。首次尚未通過驗收時，下一批仍只能選1筆。

0.2.4也提供已人工出貨的編號補記修正：管理者需執行 migrations/myship_confirm_recovery.sql。只有狀態和更新時間不同而其餘資料一致才可補記，已取消、商品或金額改變，以及CM重複仍會拒絕。

登入過期、驗證畫面、按鈕不明確、下載連結尚未支援或結果不符時，助手會停止並顯示原因。不要再上傳同一批檔案。

先在原賣貨便分頁開啟本批的結果明細，再按健康優選「讀回上一批結果」。這個按鈕只讀結果，絕不重新提交。

如果賣貨便改版或自動下載暫時失敗，可從「訂單匯入紀錄」下載原結果，在健康優選「批次紀錄」選擇「讀取本批結果檔並更新已出貨」。此方式也會核對完整資料，不必逐筆輸入 CM 編號。待實際頁面完成適配後，可恢復自動讀回。

只有明確未在賣貨便成立的訂單才使用原有「解除保留」。部分成功時保留尚未確認的訂單。頁面重新整理、助手重啟或再次點擊，均不會自動重傳上一批。
